# Hacker Club CTF Lab

### Description

Build a controlled, isolated environment for practicing offensive and defensive security. Use intentionally vulnerable targets and original challenges with explicit authorization and clear boundaries.

### Goals

Offer repeatable learning exercises while keeping the lab separate from club and public networks. Publish deployment and reset instructions.

### Potential Activities

Create beginner web challenges, investigate defensive logs and rehearse restoring disposable targets.

### Category

Cybersecurity & CTF

### Resources Needed

A virtualization host, isolated networking, challenge authors, defensive mentors and time for maintenance.

### Complexity

High

### How Can Others Participate?

Write hints, test challenges, contribute accessible walkthroughs or help validate isolation.

These are suggested activities for a community proposal, not an approved or active project. Scope and resources will be reviewed with organizers.
