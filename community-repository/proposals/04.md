# RFID & NFC Experimentation Lab

### Description

Explore RFID and NFC through authorized experiments with club-owned tags, readers and test devices. Create educational demonstrations of identification, data formats and security properties.

### Goals

Explain technology limits and defensive controls through reproducible experiments using purpose-built test materials.

### Potential Activities

Read test tags, build an inventory demo and compare documented protection features without involving real credentials.

### Category

Hardware & Electronics

### Resources Needed

Compatible readers, blank tags, owned development boards, technical documentation and mentors.

### Complexity

Medium

### How Can Others Participate?

Build a demo interface, document observations, design an introductory exercise or help manage test equipment.

These are suggested activities for a community proposal, not an approved or active project. Scope and resources will be reviewed with organizers.
