# Self-Hosted AI Security Lab

### Description

Experiment with locally hosted AI models, security evaluation and AI-assisted development in a shared learning lab. Use synthetic or openly licensed datasets and record limitations alongside results.

### Goals

Develop reproducible local inference and evaluation guides while exploring privacy, model behavior and secure integrations.

### Potential Activities

Compare small models, build a synthetic prompt-injection exercise and review generated code using known test cases.

### Category

AI & Automation

### Resources Needed

A host suitable for selected models, optional GPU capacity, storage, model licenses and evaluation volunteers.

### Complexity

High

### How Can Others Participate?

Prepare test cases, measure resource use, document installations or contribute a beginner-friendly demo.

These are suggested activities for a community proposal, not an approved or active project. Scope and resources will be reviewed with organizers.
