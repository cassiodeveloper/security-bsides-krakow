# Community purpose in every communication

All BSides Kraków communications about the Club, memberships, funding, meetups and conference must prominently state: **BSides is a community initiative, built by the community, for the community, with no profit-making purpose.**

For funding and membership communications explain that every contribution supports the Club, meetups and annual conference, including running costs; any surplus stays with the project. Apply this to web pages, emails, sponsorship materials and social posts. Do not imply a registered charitable or tax-exempt legal status or invent financial figures.
