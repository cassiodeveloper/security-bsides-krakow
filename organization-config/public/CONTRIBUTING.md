# Contributing to Security BSides Kraków

Welcome! You can help with documentation, design, testing, teaching, hardware, infrastructure or code. Read the target repository's README first; its contribution instructions may add project-specific steps.

## Choose the right place

- Propose a Hacker Club project in [Project Ideas](https://github.com/Security-BSides-Krakow/hacker-club-projects/discussions/new?category=project-ideas).
- Use the relevant repository's Issues for reproducible bugs and actionable improvements.
- Ask general participation questions in the community Discussions or email contact@bsideskrakow.pl.
- Follow SECURITY.md for sensitive vulnerabilities and CODE_OF_CONDUCT.md for conduct concerns. Do not disclose them publicly.

## Make a contribution

1. Check existing Issues, Discussions and pull requests to avoid duplication. Ask before taking on large work. A simple proposal is enough to begin.
2. Fork the public repository and create a focused branch. Organization membership is not required.
3. Make a small, understandable change. Follow existing conventions, include necessary documentation and run relevant checks. Add tests when they meaningfully verify behavior.
4. Open a pull request describing the problem, change and validation. Link the relevant Issue or Discussion. Screenshots help when changing UI; remove private information first.
5. Respond constructively to review. Maintainers normally squash changes into the default branch. Do not force-push shared branches.

Do not commit passwords, tokens, private keys, personal data or unauthorized third-party material. Use synthetic test data. Security experiments must stay within explicit authorization and agreed boundaries.

You may use AI tools, but you remain responsible for correctness, licensing, security and understanding your contribution. Never send community secrets or private reports to external tools without authorization.

## Licensing and recognition

Check each repository's LICENSE before using or contributing material. This organization does not apply a blanket license to all repositories. If licensing is unclear, ask before reusing or submitting copyrighted material. Maintainers should credit contributors and document shared results.

We cannot promise review times; this is a volunteer community. If work is paused, leave a short status update so another person can help.
