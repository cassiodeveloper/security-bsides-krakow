# Getting help

- Hacker Club ideas, questions and volunteering: [community Discussions](https://github.com/Security-BSides-Krakow/hacker-club-projects/discussions).
- Project bugs: the affected repository's Issues, with steps to reproduce and relevant version details.
- Conference, partnerships and general organization matters: [bsideskrakow.pl](https://bsideskrakow.pl/) or contact@bsideskrakow.pl.
- Conduct concerns: follow CODE_OF_CONDUCT.md and report privately.
- Security vulnerabilities: follow SECURITY.md and report privately.

Please search existing conversations first. Keep questions understandable and remove tokens, personal information and private logs. This is a volunteer community; response times depend on availability.
