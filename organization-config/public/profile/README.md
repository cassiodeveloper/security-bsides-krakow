# Security BSides Kraków

**Learn. Hack. Build. Connect.**

We are Kraków's community for people curious about cybersecurity, technology and making things together. This organization hosts our community projects, shared learning resources and open-source collaboration.

## Find your way

| Join in | Start here |
| --- | --- |
| Conference, events and community news | [bsideskrakow.pl](https://bsideskrakow.pl/) |
| Our year-round community | [Hacker Club](https://bsideskrakow.pl/hacker-club/) |

## Everyone has something to contribute

Beginners and experienced hackers are welcome. Contribute a question, documentation, a design, a test, a workshop or code. You do not need to be a GitHub organization member to participate in public repositories.

Start with the repository's README and contribution guide. Discuss larger changes before building them. Project votes express interest; organizers also consider feasibility, safety, resources and community benefit.

Please follow our [Code of Conduct](https://bsideskrakow.pl/code-of-conduct.html). Practice security research only with explicit authorization and an agreed scope.

Contact: [contact@bsideskrakow.pl](mailto:contact@bsideskrakow.pl). Never post credentials, personal data or sensitive vulnerability details in public Issues or Discussions.
